# Плеер Televik (Plixus)

Плеер записей конференц-системы Televic Plixus с дорожками по каналам и метками микрофонов.

Plixus пишет каждый канал конференции отдельным mp3: общий канал зала (Floor) и языковые
каналы (01 RUS, 02 ENG…). Программа на компьютере:

* запускает и останавливает запись на Plixus из плеера (с названием записи);
* во время записи фиксирует, когда включался и выключался каждый микрофон, — это метки;
* после остановки сама скачивает файлы записи в папку `Записи/<дата время название>/`;
* раз в минуту докачивает записи, запущенные с самой панели Plixus.

Плеер играет каналы одной записи синхронно, позволяет слушать один канал, переходить по меткам
и фильтровать метки по микрофону.

## Установка

`PleerPlixus-Setup-<версия>.exe` → «Далее»: адрес Plixus (с проверкой связи), папка для записей,
ярлык и автозапуск → «Готово». Python не нужен. Настройки потом — шестерёнка в плеере.

Собрать установщик: `pwsh installer/build.ps1 -Version 1.0.0` (нужен Inno Setup 6).

## Запуск из исходников

Нужен Python 3.10+ и компьютер в одной сети с Plixus.

```
Запустить.bat
```

или `python plixus_recorder.py`. Плеер откроется на http://localhost:8765. Окно программы
должно быть открыто, пока идёт заседание: иначе метки не запишутся.

Настройки — `config.json` рядом с программой (`host`, `rec_dir`) или шестерёнка в плеере;
переменные окружения важнее файла:

| Переменная | По умолчанию | Что это |
|---|---|---|
| `PLIXUS_HOST` | `10.0.20.32` | адрес центрального блока Plixus |
| `PLIXUS_REC_DIR` | `Записи` рядом с программой | куда складывать записи |

## Файлы

| Файл | Что это |
|---|---|
| `plixus_recorder.py` | программа: связь с Plixus, запись, метки, скачивание, веб-сервер плеера |
| `player.html` | плеер, открывается программой |
| `Запустить.bat` | запуск двойным кликом (ставит библиотеку `websockets`, если её нет) |
| `installer/` | сборка exe (PyInstaller) и установщика (Inno Setup): `build.ps1`, `PleerPlixus.iss`, `make_icon.py` |
| `mockup/` | первая вёрстка по эскизу и плеер без программы (только слушать файлы с Plixus) |
| `wiki/`, `tools/wiki_publish.py` | документация, публикуется в Яндекс Вики |

В каждой папке записи лежат каналы (`Floor.mp3`, `01 RUS.mp3`…) и `meta.json`: название,
время старта и метки `{seat, label, start, end}` в секундах от начала записи.
