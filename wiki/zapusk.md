Как запустить программу записи и плеер.

## Запуск

1. Компьютер в одной сети с Plixus (→ Доступы Д.1), установлен Python 3.10+.
2. Взять код: `git clone https://github.com/Korvova/pleer-televik` (→ Доступы Д.3).
3. Двойной клик по `Запустить.bat`. Он сам поставит библиотеку `websockets`, если её нет,
   и откроет плеер на http://localhost:8765.
4. Окно программы держать открытым всё заседание: метки микрофонов пишутся только пока она работает.

Повторный запуск, когда программа уже работает, просто открывает плеер.

## Как пользоваться

* **Записать:** ввести название → «Запись» → … → «Стоп». Через несколько секунд запись появится в списке.
* **Слушать:** выбрать запись, кнопками каналов выбрать «Все» или один канал, кликнуть метку, чтобы перейти к ней.
* **Метки одного микрофона:** выбрать его в фильтре, стрелки внизу ходят по его меткам.
* Запись, запущенная с панели Plixus, скачается сама в течение минуты, кнопка ⟳ — сразу.

## Где лежат записи

`Записи/` рядом с программой (меняется переменной `PLIXUS_REC_DIR`). В папке каждой записи:

| Файл | Что это |
|---|---|
| `Floor.mp3`, `01 RUS.mp3`, `02 ENG.mp3` | каналы |
| `meta.json` | название, время старта, метки `{seat, label, start, end}` в секундах от начала |

`Записи/_journal.json` — названия и метки, записанные до скачивания файлов. Его не удалять,
пока последние записи не скачались.

## Настройки

| Переменная | По умолчанию | Что это |
|---|---|---|
| `PLIXUS_HOST` | `10.0.20.32` | адрес Plixus |
| `PLIXUS_REC_DIR` | `Записи` рядом с программой | папка записей |

Порт плеера — 8765, слушает только этот компьютер.
